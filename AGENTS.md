# Repository guidance

This independent repository contains the public moNa2 firmware only.

- Before committing, use local Git author/committer name `ogimah` and email
  `ogimah@users.invalid`. Do not use a personal name, private email, or a
  GitHub-profile-linked identity from the execution environment.
- Do not import private `.vil` files, personal keymaps/macros, or the old
  repository's Git history into this repository.
- Preserve upstream copyrights and all bundled license/attribution texts.
- Use checked-in public test fixtures; tests must not require old Git commits.
- A successful build does not establish hardware verification.
